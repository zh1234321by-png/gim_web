# SEGM 实时观测台

## 数据链路

```text
NTRIP Caster 8.130.47.186:2101 / IONO00XAN1
       ↓ IGS SSR 4076.201
scripts/realtime_gim_bridge.py
       ↓ 球谐展开（2.5° × 5°）
SQLite 7 天滚动缓存 + http://127.0.0.1:8765
       ↓ 网站同源代理 /api/realtime/*
首页实时窗口与 /observatory
```

Caster 连接只发生在 Python 后台。浏览器不会看到 Caster 账号、密码，
也不会直接连接 2101 端口。

## Windows 本地调试

在项目根目录打开 CMD 或 PowerShell：

```powershell
python -m pip install -r scripts/requirements-realtime.txt
python scripts/realtime_gim_bridge.py --mode ntrip
```

默认配置已经是：

- Host：`8.130.47.186`
- Port：`2101`
- Mountpoint：`IONO00XAN1`
- 登录：匿名
- 本地接口：`http://127.0.0.1:8765`

另开一个窗口启动网页：

```powershell
pnpm run dev
```

打开：

```text
http://localhost:3000/observatory
```

点击地图任意网格，会请求该点最近 24 小时的 VTEC 时间序列。
观测台还可以按 UTC 日期读取当日完整历元索引，再按时间轴逐帧回放。

> Caster 只播发当前历元，不能向已经晚到的浏览器倒播。必须让
> `realtime_gim_bridge.py` 在服务器上全天运行；历史来自服务器 SQLite，
> 而不是浏览器临时缓存。程序重启时还会从已归档 SSR 文件恢复遗漏历元。

如果需要使用已有的 BNC/Python 接收程序，只让本程序监视其 SSR 输出：

```powershell
python scripts/realtime_gim_bridge.py `
  --mode watch `
  --ssr-glob "Z:\RTGIM-BNC\code\gim_receiver\输出目录\IONO00XAN1*_ION.ssr"
```

请将“输出目录”替换为现有接收程序实际写入 SSR 文件的目录。

## Linux 运行

```bash
cd /mnt/disk1/SEGMweb
python3 -m pip install --user -r scripts/requirements-realtime.txt
python3 scripts/realtime_gim_bridge.py --mode ntrip
```

另一个终端运行网站：

```bash
pnpm run build
pnpm run start -- -H 0.0.0.0 -p 3000
```

原来的端口映射可以保持：

```text
公网 TCP 520 → Linux 服务器 TCP 3000
```

网页自身的 `/api/realtime/*` 会代理到同机的 `127.0.0.1:8765`，
因此不需要把 8765 或 Caster 的 2101 端口暴露到公网。

建议安装 `deploy/segm-realtime.service.example` 为 systemd 服务并启用开机
自启动。只要服务全天运行，即使用户下午 4 点第一次打开网页，也可以回放
当天 0 点以来已经保存的所有历元。

## 可用接口

- `/health`：后台状态
- `/latest.json`：最新一个 GIM 历元
- `/frames.json?limit=24`：最近若干历元，用于地图动画
- `/timeline.json?date=2026-07-23`：指定 UTC 日期的完整历元索引
- `/frame.json?epoch=2026-07-23T08:00:00Z`：读取指定历元的完整 GIM
- `/series.json?lat=34.0&lon=110.0&hours=24`：最近 24 小时点序列
- `/series.json?lat=34.0&lon=110.0&date=2026-07-23`：指定日期点序列

网站访问这些接口时使用同源路径：

```text
/api/realtime/health
/api/realtime/latest.json
/api/realtime/frames.json
/api/realtime/timeline.json
/api/realtime/frame.json
/api/realtime/series.json
```

## 数据文件

后台运行时会在以下目录保存数据：

```text
runtime/realtime/gim.sqlite3
runtime/realtime/ssr/
```

`runtime/` 已加入 `.gitignore`，不会被打包进网页源码。SQLite 默认保留
最近 7 天数据。SSR 日文件用于程序重启时补载、后续检查和正式实时 GIM
产品生产；可通过 `--history-hours` 调整保存时长。

正式实时产品目录为：

```text
http://8.130.47.186/rt_iono/{year}/{doy}/
```

该目录适合产品检索、下载和补齐已经发布的日产品；当天尚未发布且接收服务
此前没有运行的 Caster 历元无法事后恢复，所以实时接收服务必须常驻。

## 非匿名登录

如果以后 Caster 增加账号密码，请使用环境变量，不要写进网页代码：

PowerShell：

```powershell
$env:NTRIP_USERNAME="用户名"
$env:NTRIP_PASSWORD="密码"
python scripts/realtime_gim_bridge.py --mode ntrip
```

Linux：

```bash
export NTRIP_USERNAME='用户名'
export NTRIP_PASSWORD='密码'
python3 scripts/realtime_gim_bridge.py --mode ntrip
```
