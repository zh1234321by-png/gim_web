# SEGM 网站内容更新说明

网站的人员、论文、项目、新闻、联系方式和产品目录参数都集中在 `site-content.json`。

常见更新：

- 新成员：在 `students` 中找到对应年级，向 `names` 数组追加姓名。
- 新论文：复制 `publications` 中任意一条，修改 `year`、`title`、`authors`、`journal` 和 `tag`。
- 新动态：复制 `news` 中任意一条，修改日期、标题和类别。
- 实时产品上线：将 `product.realtimeBaseUrl` 改为实时产品目录地址；网页会把“规划接入”状态切换为“服务已配置”。
- 产品云迁移：修改 `product.archiveBaseUrl`，不需要改页面代码。

JSON 对英文双引号和末尾逗号有严格要求。每次更新后建议运行一次构建检查。
