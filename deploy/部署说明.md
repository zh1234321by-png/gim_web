# SEGM 课题组网站 - 阿里云 ECS 部署说明

## 项目信息

- **项目名称**：SEGM 课题组网站
- **技术栈**：Next.js 16 (App Router) + React 19 + Tailwind CSS 4
- **Node 版本要求**：>= 22.13.0
- **包管理器**：pnpm
- **前端端口**：5200
- **实时观测台端口**：8765（内部，不对外暴露）
- **服务器**：阿里云 ECS (Ubuntu)
- **公网 IP**：8.130.47.186

---

## 快速部署

### 方式一：一键部署脚本（推荐）

```bash
# 1. 上传 deploy.sh 到服务器
scp deploy/deploy.sh root@8.130.47.186:/mnt/SEGMweb/

# 2. 登录服务器
ssh root@8.130.47.186
cd /mnt/SEGMweb

# 3. 添加执行权限
chmod +x deploy.sh

# 4. 执行完整部署
./deploy.sh all
```

### 方式二：手动部署

```bash
# 1. 安装 Node.js 22+ (Ubuntu)
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt-get install -y nodejs

# 2. 安装 pnpm
npm install -g pnpm

# 3. 安装 PM2
npm install -g pm2

# 4. 进入项目目录
cd /mnt/SEGMweb

# 5. 安装依赖
pnpm install --frozen-lockfile

# 6. 构建项目
pnpm run build

# 7. 启动服务（端口 5200）
pm2 start "pnpm start -- -H 0.0.0.0 -p 5200" --name segm-web

# 8. 保存 PM2 配置并设置开机自启
pm2 save
pm2 startup systemd -u root --hp /root
```

`deploy.sh` 支持多种操作模式：


## 阿里云安全组配置

**必须**在阿里云控制台安全组中开放以下端口：

| 端口 | 协议 | 用途 | 来源 |
|------|------|------|------|
| 5200 | TCP | 前端网站访问 | 0.0.0.0/0 |
| 22 | TCP | SSH 远程登录 | 你的 IP（建议限制） |

> 注意：实时观测台的 8765 端口不需要对外暴露，网站会通过内部代理访问。

## 实时观测台部署

项目包含一个 Python 实时观测台后台服务，用于接收 NTRIP 数据流并提供实时 GIM 数据。

### 启动实时观测台

```bash
# 安装 Python 依赖
cd /mnt/SEGMweb
python3 -m pip install --user -r scripts/requirements-realtime.txt

# 启动服务
python3 scripts/realtime_gim_bridge.py --mode ntrip
```

### 配置为 systemd 服务（推荐）

部署脚本会自动创建 systemd 服务文件：

```bash
# 启动服务
systemctl start segm-realtime

# 设置开机自启
systemctl enable segm-realtime

# 查看状态
systemctl status segm-realtime

# 查看日志
journalctl -u segm-realtime -f
```

## 常见问题

### 1. 端口被占用

```bash
# 查看端口占用
netstat -tlnp | grep 5200
# 或
lsof -i :5200
```

### 2. 访问不了网站

- 检查阿里云安全组是否开放 5200 端口
- 检查防火墙是否开放端口
- 检查 PM2 服务状态：`pm2 status`
- 查看错误日志：`pm2 logs segm-web --err`

### 3. 构建失败

- 检查 Node.js 版本是否 >= 22.13.0
- 检查依赖是否安装完整：`pnpm install`
- 查看构建错误信息
- 清理缓存后重试：`rm -rf .next && pnpm run build`

### 4. 实时观测台不工作

- 检查 Python 依赖是否安装
- 检查服务状态：`systemctl status segm-realtime`
- 查看日志：`journalctl -u segm-realtime -f`
- 检查 NTRIP 连接是否正常

### 5. 内存不足

如果服务器内存较小（小于 2GB），构建时可能会内存不足：

```bash
# 增加 swap 空间
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```
